# ELITEA-0396: @Mention of Same User Multiple Times in One Message Generates Only One Notification

**Module:** Chat Interface · **Priority:** High · **Type:** Functional

**Objective:** Verify that when a single chat message mentions the same user more than once, that user receives only one notification — not one per mention occurrence.

**Coverage:**
- One message with @User_B appearing twice = exactly 1 notification for User B
- Duplicate notification suppression within the same message request

## Preconditions

- User A and User B are members of the same Team Project and participants in a shared chat

## Test Data

Message text: "Hey @User_B, can you check this? Also @User_B, please confirm when done."

## Steps

| # | Action | Expected Result |
|---|--------|----------------|
| 1 | Log in as User A. Open the Team Project chat with User B as a participant. | Chat is open. User B is visible in the PARTICIPANTS panel. |
| 2 | In the chat input, type a message that tags @User_B more than once — e.g., 'Hey @User_B, can you check this? Also @User_B, please confirm when done.' Send the message. | Message is sent. The @User_B tag appears twice in the same chat message. |
| 3 | Log out. Log in as User B. Navigate to the Notification tab. | User B's Notification tab is open. |
| 4 | Count the notification entries generated by this single message. | Exactly 1 notification exists — not 2, despite @User_B appearing twice in the message. |

## Expected Final State

Exactly 1 notification exists — not 2, despite @User_B appearing twice in the message.

## Pass/Fail Criteria

**Pass:**
- Exactly 1 notification exists for User B from the message where they were mentioned twice

**Fail:**
- 2 or more notifications exist for User B from the single message (one per user mention occurrence)
