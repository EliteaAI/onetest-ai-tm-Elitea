# ELITEA-0616: Very long message (5000+ characters) is accepted or rejected with a clear limit message

**Module:** Elitea Chat Bot · **Priority:** Medium · **Type:** Functional

**Objective:** Verify that sending a very long message (5000+ characters) either: (a) is accepted and produces a valid assistant response, or (b) is rejected with a clear character limit error message visible to the user. The system must not silently truncate the message, hang, or crash.

## Preconditions

Support Assistant is enabled.
Tester has the panel open.

## Test Data

A text string of 5000+ characters (can be generated by repeating a paragraph)

## Steps

| # | Action | Expected Result |
|---|--------|----------------|
| 1 | Paste a 5000+ character text block into the message composer | Text is pasted; observe whether a character counter or limit indicator appears |
| 2 | Attempt to send the message | Either: message is sent and a response is received (accepted), OR a validation error is shown (e.g., "Message exceeds 4000 character limit") |
| 3 | If rejected: verify the error message is specific and actionable | Error clearly states the limit or reason; the composer retains the text for editing |
| 4 | If accepted: verify the assistant responds without timeout or crash | A valid response is received |

## Expected Final State

A valid response is received

## Pass/Fail Criteria

PASS: Clear acceptance or rejection; no hang or crash; error message (if shown) is actionable.
FAIL: Silent truncation; hang; crash; or unspecific error message.
