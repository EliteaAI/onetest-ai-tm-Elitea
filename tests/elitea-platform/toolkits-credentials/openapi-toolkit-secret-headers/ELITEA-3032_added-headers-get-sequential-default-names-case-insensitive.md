# ELITEA-3032: Added Headers Get Sequential Default Names (Header-1, Header-2, ...), Scanned Case-Insensitively

**Module:** Toolkits & Credentials / OpenAPI Toolkit Secret Headers · **Priority:** Medium · **Type:** Functional

**Objective:** Confirm, per `SecretHeadersInput.jsx`, that clicking **+ Add header** (`openapi-secret-header-add`) assigns each new row an auto-generated default name (`Header-1`, `Header-2`, ...), with the component scanning existing names **case-insensitively** before picking the next default so it never re-issues a name already in use under any casing.

---

## Preconditions

- Logged in to `{{base_url}}` with permission to create/edit an OpenAPI credential.

---

## Test Data

| Field | Value |
|-------|-------|
| Credential type | OpenAPI Configuration (any auth method) |

---

## Steps

| # | Action | Expected Result |
|---|--------|------------------|
| 1 | Open the OpenAPI credential form and click **+ Add header** once. | A new row appears with name input `openapi-secret-header-name-0` pre-filled `Header-1`, value input `openapi-secret-header-value-0`, and remove button `openapi-secret-header-remove-0`. |
| 2 | Click **+ Add header** again. | Second row defaults to `Header-2`, not `Header-1` again. |
| 3 | Manually rename the first row to `header-3` (lowercase, matching the pattern case-insensitively). | Rename succeeds (different row, not a duplicate of an existing name at this point). |
| 4 | Click **+ Add header** a third time. | The new row's default name is **not** `Header-3` (since `header-3` already exists case-insensitively) — it skips to the next unused default, e.g. `Header-4`. |

---

## Expected Final State

Default header names are always unique case-insensitively across all rows, generated by scanning existing names before assigning the next default.

---

## Pass/Fail Criteria

**Pass:** Each new row gets a case-insensitively-unique default name; the scan correctly skips names already in use under any casing.
**Fail:** A duplicate default name (even differing only in case) is assigned to a new row.
