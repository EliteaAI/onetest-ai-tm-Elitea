# ELITEA-0374: Save DOCX — Success Notification and File Persistence [Artifacts / Chat]

**Module:** Canvas · **Priority:** Critical · **Type:** Functional

**Objective:** Verify that saving an edited DOCX file in Canvas shows a success notification and persists the changes on reopen — from both Artifacts and Chat contexts.

**Coverage:**
- Save overwrites the original file and shows a success notification (Artifacts context)
- Reopening the file from Artifacts shows the saved changes
- Save works on a Chat-generated DOCX and shows a success notification (Chat context)
- Reopening the Chat-generated file shows the saved changes

## Preconditions

- Logged in to {{base_url}}
- `test.docx` available in Artifacts bucket `test-docx-bucket`
- A Chat conversation where a `.docx` file was **generated by Chat** (e.g. ask an agent to create a DOCX document)
  > **Note:** The eye/edit icon only appears on DOCX files produced as Chat output, not on user-uploaded attachments.

## Test Data

- Unique marker texts: `"SAVED_MARKER_ARTIFACTS"`, `"SAVED_MARKER_CHAT"`
- Artifacts file: `test.docx` in bucket `test-docx-bucket`
- Chat file: DOCX generated by a Chat agent in an active conversation

## Steps

| # | Action | Expected Result |
|---|--------|----------------|
| 1 | [Artifacts] Open `test.docx` from Artifacts in Canvas and type the marker text `SAVED_MARKER_ARTIFACTS` into a paragraph | Marker text appears in the editor; Save button becomes enabled |
| 2 | Click the Save button | Success notification (toast) appears confirming the file was saved |
| 3 | Close the Canvas modal, then reopen `test.docx` from Artifacts | SuperDoc loads; `SAVED_MARKER_ARTIFACTS` is present in the document |
| 4 | [Chat] Navigate to the Chat conversation, click the eye icon on the Chat-generated DOCX output, and type the marker text `SAVED_MARKER_CHAT` into a paragraph | Marker text appears in the editor; Save button becomes enabled |
| 5 | Click the Save button | Success notification (toast) appears confirming the file was saved |
| 6 | Close the Canvas modal, then reopen the same Chat-generated DOCX by clicking the eye icon again | SuperDoc loads; `SAVED_MARKER_CHAT` is present in the document |

## Expected Final State

SuperDoc loads; `SAVED_MARKER_CHAT` is present in the document

## Pass/Fail Criteria

**Pass:**
- Save succeeds with a success notification in both contexts
- Marker text is visible on reopen in both contexts

**Fail:**
- No success notification appears in either context
- File reverts to original content on reopen in either context
- Save button is unresponsive
