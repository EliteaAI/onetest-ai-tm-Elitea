# ELITEA-0377: Open DOCX in SuperDoc Canvas Editor [Artifacts / Chat]

**Module:** Canvas · **Priority:** Critical · **Type:** Functional

**Objective:** Verify that clicking the View/Edit icon on a `.docx` (Word Document) file opens the SuperDoc Canvas editor as a modal overlay with document content loaded — in both Artifacts and Chat contexts.

**Coverage:**
- Canvas modal opens from Artifacts
- Canvas modal opens from Chat
- SuperDoc editor renders text content, paragraphs, and basic formatting
- Note: Layout rendering in complex documents may have visual discrepancies

## Preconditions

- Logged in to {{base_url}}
- Private project with an Artifacts bucket containing a `.docx` (Word Document format) file
- A Chat conversation where a `.docx` file was **generated by Chat** (e.g. ask an agent to create a DOCX document — the file appears as a Chat output, not a user upload)
  > **Note:** Simply uploading a DOCX file as a message attachment does NOT show the eye/edit icon. The icon only appears on DOCX files produced as output by the Chat agent.

## Test Data

- File: `test.docx` — multi-paragraph Word Document with bold text, a list, and a table
- Artifacts bucket name: `test-docx-bucket`

## Steps

| # | Action | Expected Result |
|---|--------|----------------|
| 1 | [Artifacts] Click the eye icon on `test.docx` in the Artifacts bucket file list | Canvas modal opens as a modal overlay |
| 2 | Inspect the modal content | SuperDoc editor is visible with the DOCX document content loaded — text and paragraphs are rendered |
| 3 | Inspect the modal header/toolbar | SuperDoc toolbar is present; Save, Discard, and X (close) controls are visible |
| 4 | Close the modal, then navigate to Chat, open the conversation with `test.docx` attached, and click the eye icon on the attachment | Canvas modal opens from Chat context with the same document rendered in SuperDoc |

## Expected Final State

Canvas modal opens from Chat context with the same document rendered in SuperDoc

## Pass/Fail Criteria

**Pass:**
- Modal opens in both Artifacts and Chat contexts
- Document content (text, paragraphs) is rendered in SuperDoc
- Save, Discard, and X controls are visible

**Fail:**
- Modal does not open in either context
- SuperDoc fails to load; blank/white editor is shown
- Toolbar controls are missing
- Console error or crash is observed
