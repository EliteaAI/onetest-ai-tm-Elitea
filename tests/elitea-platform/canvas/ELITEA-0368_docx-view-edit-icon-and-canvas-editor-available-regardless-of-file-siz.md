# ELITEA-0368: DOCX View/Edit Icon and Canvas Editor Available Regardless of File Size in Artifacts and Chat (< 2MB and > 2MB)

**Module:** Canvas · **Priority:** Critical · **Type:** Functional

**Objective:** Verify the View/Edit (eye) icon is present and opens the SuperDoc Canvas editor for `.docx` files both below and above the 2MB threshold — in both the Artifacts bucket file list and Chat conversation output.

**Coverage:**
- View/Edit icon visible and enabled for `.docx` < 2MB in Artifacts
- View/Edit icon visible and enabled for `.docx` > 2MB in Artifacts (bug fix validation)
- View/Edit icon visible and enabled for `.docx` < 2MB in Chat (agent-generated output)
- View/Edit icon visible and enabled for `.docx` > 2MB in Chat (agent-generated output, bug fix validation)
- SuperDoc Canvas editor opens and renders content for both sizes in both contexts
- No "File too large to preview" error shown for any `.docx` file
- Basic text editing is functional inside the editor for both sizes and both contexts

## Preconditions

- Logged in to {{base_url}}
- Access to Artifacts menu with at least one bucket
- Permission: configuration.artifacts.artifacts.view
- A Chat conversation is available where a `.docx` file was **generated by a Chat ** as output (e.g. ask an agent to create a DOCX document — the file appears as a Chat output attachment)
- Two such Chat conversations exist: one where the chat produced a `.docx` < 2MB, and one where the chat produced a `.docx` > 2MB

## Test Data

**Artifacts:**
- File A: test_small.docx — ~500KB (< 2MB), contains at least one paragraph of text
- File B: test_large.docx — ~2.5MB or larger (> 2MB), e.g. a document with embedded images

**Chat:**
- Chat A: conversation where agent produced a `.docx` output < 2MB
- Chat B: conversation where agent produced a `.docx` output > 2MB

## Steps

| # | Action | Expected Result |
|---|--------|----------------|
| 1 | Navigate to Artifacts from the sidebar. Select any available bucket. | Bucket file list is displayed. |
| 2 | Click 'Upload' and select test_small.docx (~500KB). Confirm the upload. | File appears in the file list with its size shown. |
| 3 | Locate test_small.docx in the File Table. Inspect the Actions column. | The View/Edit (eye) icon is visible and enabled. |
| 4 | Click the View/Edit (eye) icon on test_small.docx. | SuperDoc Canvas editor opens as a modal overlay. Document text content is rendered. No error is shown. |
| 5 | Click inside the document and type EDIT_TEST. | Typed text appears in the document. Save and Discard buttons become enabled. |
| 6 | Close the Canvas modal. Click 'Upload' and select test_large.docx (> 2MB). Confirm the upload. | File appears in the file list with its size shown. |
| 7 | Locate test_large.docx in the File Table. Inspect the Actions column. | The View/Edit (eye) icon is visible and enabled. |
| 8 | Click the View/Edit (eye) icon on test_large.docx. | SuperDoc Canvas editor opens as a modal overlay. Document content is rendered. No 'File too large to preview' error appears. |
| 9 | Click inside the document and type EDIT_TEST. | Typed text appears in the document. Save and Discard buttons become enabled. |
| 10 | Navigate to Chat. Open Chat A (conversation where agent produced a `.docx` output < 2MB). Locate the DOCX attachment chip in the agent output. | The View/Edit (eye) icon is visible on the DOCX attachment chip (always displayed, not hover-triggered). |
| 11 | Click the View/Edit (eye) icon on the Chat A DOCX attachment. | SuperDoc Canvas editor opens as a modal overlay. Document text content is rendered. No error is shown. |
| 12 | Click inside the document and type EDIT_TEST. | Typed text appears in the document. Save and Discard buttons become enabled. |
| 13 | Close the Canvas modal. Navigate to Chat B (conversation where agent produced a `.docx` output > 2MB). Locate the DOCX attachment chip in the agent output. | The View/Edit (eye) icon is visible on the DOCX attachment chip (always displayed, not hover-triggered). |
| 14 | Click the View/Edit (eye) icon on the Chat B DOCX attachment. | SuperDoc Canvas editor opens as a modal overlay. Document content is rendered. No 'File too large to preview' error appears. |
| 15 | Click inside the document and type EDIT_TEST. | Typed text appears in the document. Save and Discard buttons become enabled. |

## Expected Final State

Typed text appears in the document. Save and Discard buttons become enabled.

## Pass/Fail Criteria

**Pass:**
- View/Edit icon present and enabled for both .docx files in Artifacts (< 2MB and > 2MB)
- View/Edit icon present on DOCX agent-output attachments in Chat (< 2MB and > 2MB)
- Canvas opens and renders content for both sizes in both contexts without errors
- Text editing functional and Save/Discard buttons activate for all four scenarios

**Fail:**
- Icon missing or disabled for any .docx file in Artifacts or Chat
- "File too large to preview" shown for the > 2MB .docx in Artifacts or Chat
- Canvas shows blank modal or error for any file size in either context
- Typed text does not appear or Save/Discard buttons stay disabled
