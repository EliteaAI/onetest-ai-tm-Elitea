## Preconditions

- User is logged in to `{{base_url}}`
- An Artifact toolkit exists, configured with a valid bucket
- An agent exists with the Artifact toolkit attached

## Test Data

| Field | Value |
|-------|-------|
| URL | `{{base_url}}/app/` |
| Variant A | Agent prompt: "Create and save 2 files: file1.txt with content 'Hello' and file2.txt with content 'World'" |
| Variant B | Agent prompt: "Create and save 3 files in the same folder: report1.txt, report2.txt, report3.txt, each with distinct content" |
| Variant C | Agent prompt: "Create and save 3 files: output/a.txt, output/b.txt, output/c.txt, each with distinct content" |

## Steps

| # | Action | Expected Result |
|---|--------|-----------------|
| 1 | Navigate to `{{base_url}}/app/agents` and open the agent with the Artifact toolkit attached | Agent detail page loads |
| 2 | In the embedded chat, send the prompt from Variant A | Agent processes the request and responds confirming files were saved |
| 3 | Navigate to `{{base_url}}/app/artifacts` and open the configured bucket | Bucket file list is displayed |
| 4 | Count and list all files visible in the bucket | Both file1.txt and file2.txt appear in the list |
| 5 | Click the download action for file1.txt | file1.txt downloads successfully with correct content |
| 6 | Click the download action for file2.txt | file2.txt downloads successfully with correct content |
| 7 | Repeat steps 1–6 using Variant B (3 files, same folder) | All 3 files are visible and downloadable |
| 8 | Repeat steps 1–6 using Variant C (3 files, different folder paths) | All 3 files are visible at their respective paths and downloadable |

## Expected Final State

All files generated by the agent in each variant are present in the artifact bucket and can each be individually downloaded with correct content. No files are missing from the bucket list.

## Pass/Fail Criteria

**Pass:**
- All N files specified in the agent prompt appear in the artifact bucket after agent run
- Each file downloads individually with content matching what the agent was instructed to create
- No files are silently lost or overwritten

**Fail:**
- Only one file (or fewer than N) is visible in the artifact bucket after a multi-file agent run
- Any file fails to download or downloads with empty/incorrect content
- The artifact bucket shows 0 files after the agent run
