# ELITEA-0881: Webhook Trigger (Custom) — Valid Authentication and Request Handling

**Module:** Entrypoint Trigger Type · **Priority:** High · **Type:** Functional

**Objective:** Verifies that a POST request with the correct X-Webhook-Token header triggers the pipeline, that the raw body is passed as pipeline input, that the HTTP response is immediate (non-blocking), and that non-POST methods are rejected.

## Preconditions

A pipeline with Custom Webhook trigger configured and saved
The webhook URL is known; the auto-generated secret value has been copied from the UI Webhook config
A tool to send HTTP requests is available (e.g., curl, Postman)

## Test Data

Webhook URL: {base_url}/webhook/prompt_lib/{project_id}/{version_id}/custom
Secret: (auto-generated value — copy from UI Webhook settings before running this test)
Request body: {\"message\": \"webhook test input\"}
Empty body: (no body)

## Steps

| # | Action | Expected Result |
|---|--------|----------------|
| 1 | Send a POST request to the webhook URL with header 'X-Webhook-Token: <auto-generated-secret-copied-from-UI>' and body '{"message": "webhook test input"}' | HTTP 2xx response is returned immediately (without waiting for pipeline execution to complete) |
| 2 | Navigate to the pipeline's run history | A new run entry is visible |
| 3 | Confirm the pipeline execution completed successfully | Run status is successful |
| 4 | Inspect the run's input in the run history detail | The raw POST body '{"message": "webhook test input"}' is shown as the pipeline input |
| 5 | Send a POST request with an empty body and the correct token | HTTP 2xx response; pipeline triggers; input is empty or uses Entrypoint-configured variables |
| 6 | Send a POST request with a large payload body (e.g., 10KB+ JSON) and correct token | HTTP 2xx response; pipeline triggers without error |

## Expected Final State

HTTP 2xx response; pipeline triggers without error

## Pass/Fail Criteria

PASS: 2xx response immediately on valid POST; pipeline executes; raw body = input; empty body accepted; large body accepted
FAIL: Pipeline does not trigger on valid request; response delayed (blocking); input is not the raw body; large body causes error
